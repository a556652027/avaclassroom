● 明白了！dashboard.html 的啟用數量旁邊的百分比是去年同期成長率 (Year-over-Year 
  Growth)，不是完成百分比。

  計算邏輯（lines 867-946）：

  // 假設你的數據：
  今年啟用數量: 2339 台
  今年時間範圍: 例如 2024/01/01 到 2024/12/01

  // 1. 計算去年同期時間範圍
  去年時間範圍: 2023/01/01 到 2023/12/01

  // 2. 取得去年同期的啟用數量
  API 請求去年同期資料 → 取得去年啟用數量

  // 3. 計算成長率 (line 928)
  成長率 = (今年啟用數量 - 去年啟用數量) / 去年啟用數量 × 100%
  成長率 = (2339 - 去年數量) / 去年數量 × 100%

  // 如果顯示 -43.5%，表示：
  -43.5% = (2339 - 去年數量) / 去年數量 × 100%
  → 去年數量 ≈ 4136 台

  驗算：(2339 - 4136) / 4136 × 100% = -43.47% ✓

  所以這個 -43.5% 的意思是：
  - 今年同期啟用了 2339 台
  - 去年同期啟用了約 4136 台
  - 今年比去年下降了 43.5%（負成長）

  這是年度同期對比成長率，不是目標完成率。打開瀏覽器的
  Console，你會看到類似這樣的輸出：

  今年範圍: 2024/01/01 到 2024/12/01 啟用數量: 2339
  去年範圍: 2023/01/01 到 2023/12/01
  去年啟用數量: 4136
  成長率計算: -43.5%
