各html 放專案目錄下 可以省去許多相對位置的問題

scripts  自己的函式庫 (可以拿去其他專案使用)

    #.html  跟頁面有相關
    lib 共用自製函式庫
        sdk.lib.util.js 通用函式 像 cookie 操作  json 轉換 等等等
        sdk.lib.net.js  基本的 網路發送 request 相關功能 (指向IP在這邊) 

modules (各專案獨立) 
    各頁面會呼叫以 scripts 為底層的function

        app.module.login.js  登入用的 api 可能 會有該專案自訂的 json 或其他格是的資料內容

locales
    各種語系相關

view
    各頁面元件2操作(各頁面獨立)

components
    各頁面會共用到的元件

vender
    其他套件 可能藉由 npm 或其他管道安裝

css
    loading.style  各式各樣 載入中 等待的 dialog 
        loading.scan.css   載入中 等待的 dialog
